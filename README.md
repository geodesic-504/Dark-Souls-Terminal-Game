# Dark-Souls-Terminal-Game
Recreation of Dark Souls Artorias of the Abyss as a simple terminal game

If you have Java 11 or newer installed, to run the game you can download just game.java. In your terminal, navigate to the folder with the java file and then enter "java game.java".

Alternatively, if you do not have java installed and do not wish to install it, you can download Dark_Souls_Terminal_Game.zip on the Releases page.
