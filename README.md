# Dark-Souls-Terminal-Game
Recreation of Dark Souls Expansion, Artorias of the Abyss, as a simple terminal game

If you have Java 11 or newer installed, to run the game you can download just game.java. In your terminal, navigate to the folder with the java file and then enter "java game.java".

Alternatively, if you do not have java installed and do not wish to install it, you can download the folder Dark_Souls_Terminal_Game, and double click "start_game_in_terminal.bat" inside that folder. Dark_Souls_Terminal_Game.exe works as well, but you must make sure that it uses the terminal rather than CMD, as the colors will not render properly in CMD.
